## 使用指南

### 閱讀順序建議

1. 如果您是第一次接觸此系統，建議按照以下順序閱讀：
   - 系統架構概覽 → 資料模型規格 → 功能模組規格 → 特殊功能規格 → 技術架構規格 → 資料庫規格

2. 如果您需要了解特定功能：
   - 直接查閱相關的功能模組或特殊功能規格文件

3. 如果您需要進行系統維護或重構：
   - 重點閱讀技術架構規格和資料庫規格

### 文件維護

- 當程式碼有重大變更時，應同步更新相關規格文件
- 規格文件應保持與實際實作的一致性
- 新增功能時，應在相應的規格文件中添加說明

## 系統快速概覽

**系統名稱**: Contoso University 管理系統

**系統類型**: ASP.NET MVC 5 Web 應用程式

**主要功能**:
- 學生資訊管理（CRUD、分頁、搜尋）
- 課程管理與教材上傳
- 講師管理與辦公室分配
- 部門管理
- 即時通知系統
- 待辦事項管理
- 註冊統計報表

**技術棧**:
- .NET Framework 4.8.2
- ASP.NET MVC 5
- Entity Framework Core 3.1.32
- SQL Server LocalDB
- MSMQ (Microsoft Message Queuing)
- Bootstrap 5.3.3
